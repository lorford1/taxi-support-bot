# КАТЕГОРИЯ: Выплаты

## Проблема: Деньги не пришли
### Формулировки:
- деньги не пришли
- не получил зарплату
- где мои деньги
- перевод завис
- когда будут деньги
### Решение:
1. Убедиться, что запрос на вывод успешно сформирован
2. Проверить статус ПП в банке
3. Сообщить водителю: деньги поступят в течение суток
### Нужен менеджер: false

## Проблема: Недостаточно средств для вывода
### Формулировки:
- недостаточно средств
- на счете мало денег
- не хватает баланса
### Решение:
Сообщить водителю его реальный баланс и попросить сделать новый запрос
### Нужен менеджер: false

## Проблема: Превышение квоты вывода
### Формулировки:
- квота превышена
- лимит вывода
- не могу вывести больше
### Решение:
1. Проверить квоту в пульте ТП
2. Установить новое значение при необходимости
3. Попросить водителя сделать новый запрос
### Нужен менеджер: true

## Проблема: Ошибка в реквизитах карты
### Формулировки:
- реквизиты неверны
- карта не принимает
- ошибка в номере карты
### Решение:
Попросить водителя проверить реквизиты и сделать новый запрос
### Нужен менеджер: false

## Проблема: Нет основания для выплаты
### Формулировки:
- нет договора
- не загружен документ
- нужны документы
### Решение:
1. Сообщить менеджеру для загрузки договора
2. Проверить появление основания в запросе
### Нужен менеджер: true
